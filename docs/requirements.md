# StorageSlim 要件定義書（ドラフト）

最終更新: 2026-08-10
ステータス: Draft

## 1. 概要

`StorageSlim` は、画像ファイルをクラウド保存、共有、アーカイブの前にローカル PC 上で最適化するためのデスクトップアプリです。

本アプリは、現在別々に存在している以下の役割を1つに統合することを目的とします。

- Photoshop ベースのリサイズ・書き出し運用
- Node.js ベースの画像圧縮・フォーマット変換運用
- 変換後ファイルへのタイムスタンプ補正運用

本ドラフトは、初期リリースにおける画像最適化機能を対象とします。動画圧縮は本フェーズの対象外です。

## 2. プロダクト目的

`StorageSlim` は、画像を外部サーバーへアップロードすることなく、ユーザーの PC 上だけでファイルサイズを削減できるようにします。

主な提供価値は以下です。

- クラウド保存前の容量削減
- ローカル完結によるプライバシー確保
- 複数画像の一括処理
- 削減できた容量の分かりやすい可視化

## 3. 想定ユーザー

- Google Photos、iCloud Photos、OneDrive、Dropbox、NAS などへ写真を保存するユーザー
- コマンドラインを使わずに画像を軽量化したいユーザー
- 書き出し設定を一定に保ちたいユーザー
- 変換後もファイル時刻を維持したいユーザー

## 4. 対象範囲

初期対象範囲は以下とします。

- 画像リサイズ
- 品質調整または形式ごとの圧縮設定
- フォーマット変換
- メタデータ削除
- タイムスタンプ補正
- バッチ処理
- Saved 容量の結果表示

## 5. 対象外

本フェーズでは以下を対象外とします。

- 動画圧縮
- PDF 最適化
- クラウドアップロード連携
- 外部 API を使った処理
- AI 補正やアップスケーリング
- 画像編集機能全般

## 6. 基本方針

- ローカルファースト: 処理はユーザー端末上で完結する
- 安全性優先: 初期状態では元ファイルを上書きしない
- バッチ前提: 複数ファイルをまとめて処理できる
- 成果重視: Saved 容量を主要な UX 指標とする
- クロスプラットフォーム: Windows / macOS 両対応とする
- 技術方針: デスクトップ基盤は `Tauri`、画像処理の中核は `libvips 系` を採用する

## 7. 機能要件

### 7.1 入力形式

初期版の入力形式は以下とする。

- オリジナル形式を維持
- GIF
- JPEG / JPG
- PNG
- WebP
- AVIF
- HEIC
- HEIF

補足:

- `オリジナル形式を維持` は、入力ファイルと同じ形式での再出力を意味する
- HEIC / HEIF は初期版で実現したい対象とする
- 非対応ファイルはスキップし、エラー状態を表示する

### 7.2 出力形式

初期版の出力形式は以下とする。

- オリジナル形式を維持
- GIF
- JPEG
- PNG
- WebP
- AVIF

補足:

- HEIC / HEIF は、入力ファイルが HEIC / HEIF の場合に `オリジナル形式を維持` で再出力できることを目標とする
- 初期版では、一般的な変換先として `HEIC / HEIF` を明示選択することは必須としない
- 基本方針として、入力形式と同じ形式でリサイズや圧縮のみを行えることが望ましい
- `オリジナル形式を維持` による HEIC / HEIF 再出力は、HEIF エンコーダを同梱したビルドに限って提供する

### 7.3 ファイル投入

以下をサポートする。

- ドラッグアンドドロップによる複数ファイル追加
- ファイル選択ダイアログによる複数ファイル追加
- フォルダ単位の投入

フォルダ投入時の要件:

- 再帰的にサブフォルダを探索して処理する
- 出力時もフォルダ構造を維持する

投入後の一覧には少なくとも以下を表示する。

- ファイル名
- 元の形式
- 元のファイルサイズ
- 元の画像寸法

### 7.4 リサイズ

以下の指定方法に対応する。

- 幅指定
- 高さ指定
- 長辺指定

基本動作:

- アスペクト比は維持する
- 初期状態では拡大しない

### 7.5 品質調整・圧縮設定

形式ごとに適切な調整項目を提供する。

最低要件:

- JPEG: 品質設定
- WebP: 品質設定
- AVIF: 品質設定
- PNG: 圧縮レベル設定
- GIF: 色数設定

GIF に関する追加要件:

- アニメーション GIF はアニメーションを保持したまま処理する

初期 UX 方針:

- 形式ごとの設定差を吸収しつつ、分かりやすい基本 UI を採用する

### 7.6 フォーマット変換

以下をサポートする。

- 対応形式間の変換
- 同一形式での再エンコード
- オリジナル形式を維持したままの再出力

制約:

- アニメーション GIF から非アニメ形式への変換は、初期版では不可とする
- 上記ケースでは、理由が分かるエラーを表示する
- 入力形式ごとの出力可否は `docs/format-matrix.md` を正本とする
- HEIC / HEIF の `オリジナル形式を維持` が未対応のビルドでは、対象ファイル単位で理由付き失敗を返す

出力拡張子は選択した出力形式に一致させる。

### 7.7 メタデータ削除

初期版では少なくとも以下の選択肢を提供する。

- メタデータを削除する
- メタデータを保持する

保持時の基本方針:

- EXIF
- ICC profile
- GPS 情報

を含めて、可能な限り保持する。

補足:

- 形式やライブラリの制約により完全保持できない場合がある
- UI やドキュメントでは、保持はベストエフォートであることを明示する

### 7.8 タイムスタンプ補正

処理後ファイルに対して、元ファイルのタイムスタンプを引き継ぐ機能を提供する。

対象:

- 作成日時（CreationTime）
- 更新日時（LastWriteTime）

要件:

- 出力ファイル生成後に自動で補正処理を行う
- `作成日時を引き継ぐ` と `更新日時を引き継ぐ` を個別に選択できる
- 初期値は両方 ON とする
- 日本語表記でユーザーに分かる形で提示する

### 7.9 出力動作

上書きについて:

- 上書きする / しないを選択可能とする
- 既定値は `上書きしない` とする
- 上書きを有効化する場合は、明示的な警告または確認を行う

出力先として以下をサポートする。

- `Desktop/@StorageSlim/output`
- ユーザー指定フォルダ

ファイル名要件:

- 上書きしない場合の既定ファイル名は `元ファイル名` とする
- 出力形式に応じて拡張子を変更する
- 同名衝突時は末尾に連番を付与して回避する

### 7.10 バッチ処理

複数ファイルを1回で処理できるようにする。

要件:

- 1ファイル失敗しても残りの処理を継続する
- 成功分は保存する
- 失敗した対象ファイルと理由を表示する
- 全体進捗を表示する

### 7.11 結果表示

ファイルごとに少なくとも以下を表示する。

- Original size
- Optimized size
- Saved size
- Saved %
- 出力形式
- 出力後寸法

全体集計として少なくとも以下を表示する。

- 総ファイル数
- 成功数
- 失敗数
- 総削減容量

`Saved size` は UI 上の主要指標として扱う。

## 8. UX 要件

主な操作フローは以下とする。

1. ファイルを追加する
2. 出力設定を選ぶ
3. 最適化を実行する
4. 結果を確認する

初期版では視覚比較 UI は不要とし、必要な設定 UI と結果表示を優先する。

最低限必要な UI 領域:

1. ファイル投入エリア
2. 設定エリア
3. 処理進捗エリア
4. 結果表示エリア

## 9. 非機能要件

### 9.1 対応プラットフォーム

必須:

- Windows
- macOS

### 9.2 プライバシー

必須:

- ユーザー画像を外部サーバーへアップロードしない
- コア機能にクラウド処理を依存させない

`100% local processing` のような表現は、実装上それが完全に事実である場合のみ使用可能とする。

### 9.3 性能

数十枚から数百枚の画像を対象としたバッチ処理で実用になることを目標とする。

初期期待値:

- バッチ処理中に過剰なメモリ消費を避ける
- 1件の失敗で全体停止しない

### 9.4 信頼性

以下を満たすこと。

- 破壊的動作を既定にしない
- 失敗ファイルを明確に表示する
- 一部失敗時でも成功分の出力は保持する

## 10. MVP 案

MVP で最低限含める対象:

- 入力: GIF / JPEG / PNG / WebP / AVIF / HEIC / HEIF
- 出力: オリジナル維持 / GIF / JPEG / PNG / WebP / AVIF
- 複数ファイル投入
- フォルダ投入
- 再帰処理
- フォルダ構造維持
- 幅 / 高さ / 長辺リサイズ
- 形式ごとの圧縮設定
- メタデータ削除 / 保持
- タイムスタンプ補正
- 上書き選択
- 失敗理由表示
- Saved 容量表示
