StorageSlim をご購入いただきありがとうございます
==================================================

このファイルには、インストール方法と初回起動時の操作を記載しています。
初回起動時に OS の警告が表示されますので、お手数ですが先にお読みください。


1. 動作環境
-----------

【Windows 版】
  Windows 11（64bit）

  ※ Windows 10 では動作確認を行っていないため、対応しておりません。
     ご購入前に、設定 →「システム」→「バージョン情報」で
     「エディション」が Windows 11 になっているかご確認ください。

【Mac 版】
  Apple Silicon 搭載 Mac（M1 以降）
  macOS 11 Big Sur 以降

  ※ Intel 搭載の Mac では動作しません。
     ご購入前に、画面左上のアップルメニュー →「このMacについて」で
     「チップ」の欄が Apple M1 / M2 / M3 などになっているかご確認ください。


2. インストール
---------------

【Windows 版】
  StorageSlim_0.1.0_x64-setup.exe を実行してください。

【Mac 版】
  StorageSlim_0.1.0_aarch64.dmg を開き、StorageSlim のアイコンを
  「アプリケーション」フォルダへドラッグしてください。


3. 初回起動時の警告について（重要）
-----------------------------------

本アプリには有料のコード署名を付けていないため、初回起動時に OS の警告が
表示されます。故障や不具合ではありません。以下の手順で起動できます。

【Windows 版】
  1. インストーラーを実行すると
     「WindowsによってPCが保護されました」と表示されます
  2.「詳細情報」をクリックします
  3.「実行」ボタンが表示されるので、クリックします

【Mac 版】
  1. アプリケーションフォルダの StorageSlim をダブルクリックします
  2.「開発元を検証できないため開けません」と表示されるので
     ダイアログを閉じます
  3. アップルメニュー →「システム設定」を開きます
  4. 左側のリストから「プライバシーとセキュリティ」を選びます
  5. 画面を下にスクロールすると
     「"StorageSlim"は開発元を確認できないため使用がブロックされました」
     という項目があります。その右の「このまま開く」をクリックします
  6. 確認画面が出たら「開く」を選びます
     （Mac のパスワードまたは Touch ID を求められる場合があります）
  7. 次回以降は、通常どおりダブルクリックで起動します

  ※ 手順 5 の項目は、一度アプリの起動を試みた直後にのみ表示されます。
     見当たらない場合は、手順 1 からやり直してください。


4. 使いかた
-----------

  1. 画面右上で「画像圧縮」または「動画圧縮」を選びます
  2. ファイルまたはフォルダを画面へドラッグ&ドロップします
     （「ファイル追加」「フォルダ追加」ボタンからも選べます）
  3. 出力先フォルダを確認し、「圧縮を実行」を押します

  ・フォルダを投入すると、中のファイルを再帰的に探して処理します。
    出力先にはフォルダ構造がそのまま再現されます。
  ・元のファイルは変更しません。出力先へ新しいファイルを作成します。
  ・処理前に、失敗しそうな入力や注意が必要な入力を一覧へ表示します。
  ・処理中は一時停止・停止ができます。途中で止めても、
    それまでに成功した分は保存されます。


5. 困ったときは
---------------

Q. 動画圧縮で「FFmpeg が見つかりません」と表示される

  通常は同梱の FFmpeg が自動的に使われるため、この表示は出ません。
  もし表示された場合は、インストールが正しく完了していない可能性があります。
  一度アンインストールしてから、再度インストールをお試しください。

Q. 出力されたファイルが元より大きくなった

  すでに圧縮済みのファイルを再圧縮すると起こることがあります。
  結果一覧に増加分が表示されますので、その場合は元のファイルを
  そのままお使いください。

Q. 処理が失敗するファイルがある

  結果一覧の「状態」欄に理由を表示します。よくある原因は次の2つです。
  ・非常に大きな画像で、読み込みに必要なメモリが上限を超えている
    →「品質調整・その他」の「デコード上限」を上げてください
  ・アニメーション GIF を GIF 以外へ変換しようとしている
    → アニメーション GIF は GIF 出力のみ対応しています

Q. 動画の副音声や字幕が消えた

  仕様です。先頭の映像 1 本と音声 1 本のみを出力します。
